## 新規の指摘（文言 T1〜T10、見た目/構成 T11〜T13）

### T1. 「コード」系の用語が6つ乱立し、違いが説明されていない
アプリ全体で、招待 / 連絡先コード / 確認用コード / 確認コード / 共有ID / MID が併存する。特に紛らわしいのは「確認用コード」（招待ダイアログ）と「確認コード」（グループのメンバーメニューの「確認コードを表示」）で、同じものか別物かUIからは判別できない。「MID」は「共有ID (またはMID)」と併記されるだけで説明がない。生成元ごとに命名した跡がそのまま残っている典型。
- 証拠: aislop_invite.png（招待ダイアログ）。

### T2. 記号の書式が画面ごとにバラバラ
- ラベルのコロン: ステータス画面と設定>ネットワークでは半角「:」付きラベル（「状態:」「接続方法:」）が並ぶ一方、他の画面はコロンなし。さらに「WSS :59998, TLS off」はコロンの前に空白が入る（実測）。
- 括弧: 「共有ID (またはMID)」は半角括弧＋前に空白、「ビット(Mbps)」「バイト(MB/s、MiB/s)」は半角括弧で空白なし、説明文では全角括弧、診断ログ説明では「ください(無効にすると…」と半角括弧が空白なしで直結。1つのアプリ内で4通りある。

### T3. 数値と単位の間隔が統一されていない
「3秒前に更新」（ステータス、密着）vs「1 分前」（設定>アップデート、空白あり）。容量は「1 GiB」「0.0 MiB」と空白あり。表記ルールが画面ごとに生成されている。

### T4. 「再起動で反映」の言い回しが3種類
設定内で「変更は次回起動時に反映されます。」（プライバシーと保存）、「再起動後に反映」（同画面の別項目、体言止め）、「変更は Miasma の再起動後に反映されます。」（ネットワーク）。同じ意味の注意書きが画面ごとに別文。

### T5. 同じ行為の動詞が揺れる
グループを離れる行為は、グループ情報では「退出する」、設定>一般の説明では「ワンクリックで抜けられます」。「抜ける/退出する」が混在。

### T6. 見出しとラベルの重複・二重配置
- 設定>アップデート: 見出し「更新」の直下にラベル「更新:」。見出しを復唱している。
- ステータス: 「トランスポート」という見出しが、セクション見出しと表の見出しで2回出る。
- 「診断情報をコピー」「レポートを保存」の2ボタンが、ステータスタブと設定>このアプリについての「操作」に重複配置されている。どちらが正なのか利用者に分からない（S2の継ぎ接ぎ感の実例）。

### T7. 同名の「詳細」ボタンが複数あり、指す先が曖昧
設定>プライバシーと保存だけで「詳細」が2つ（高度な暗号化の詳細、他の人のための保管の詳細）。ステータス/ホームにも「詳細」がある。読み上げ・音声操作では区別できない。

### T8. 浮いたテキスト行（配置ミスに見える生成物）
設定>プライバシーと保存のラジオ群の途中に、静的テキスト「詳細：相手が使えないときは標準の保護で送る」が挟まっている。見出しでも説明でもない位置で、折りたたみUIのラベルがそのまま残ったように見える。

### T9. 口語・宣伝調の混入
- 連絡先の状態が「送れます」（体言止めならぬ動詞の言い切りで、状態ラベルとして雑）。
- 「ワンクリックで抜けられます」（設定>一般の説明、宣伝調）。
- 「0 にすると諦めずに続けます」（設定>ネットワーク、口語）。
- 「各ファイルがどこまで進んだかを正確に確認できます」（ファイル>転送、「正確に」が根拠のない強調）。
全体は丁寧な説明文で統一されているのに、所々に口調の違う文が混ざる。

### T10. ラベルの折り返しが単語の途中で切れる
設定>ネットワークで、左ラベルが「中継サーバーのアドレス:」→「アドレス: / ス:」、「同じネットワーク内の探索:」→「探 / 索:」と文字単位で割れる。ラベル列の幅と禁則処理が詰められていない。
- 証拠: aislop_network.png。

### T11. 招待ダイアログのアクション様式が3種混在
同じダイアログ内で、「招待メッセージをコピー」だけ塗りボタン、「連絡先コードをコピー」「QRコードを表示」は橙色テキストリンク、「あなたの連絡先コード」「あなたの確認用コード」は展開行（▸）、「完了」もテキストリンク。どれが主操作か、押せるものと開くものの区別が様式から読み取れない。
- 証拠: aislop_invite.png。

### T12. ファイルのサブタブ分類が重なっている
転送 / 保存 / 取得 / 送信 / 受信箱 / 送信済み の6つで、「取得」と「受信箱」、「送信」と「送信済み」の違いが名前から分からない。概念を並べただけで整理されていない分類。

### T13. かんたん表示でもチャットの文言はテクニカルと同一
かんたん表示に切り替えても、チャットの説明文・ステータス文（「2人中0人に届きました（待機中）」）・注記はテクニカルと完全に同じだった。モードで変わるのはホーム画面とタブ名と設定項目の出し分けのみ。「かんたん」がどこまでを指すのか（言葉遣いは対象外なのか）が利用者に伝わらない。第1段階 S4 の実測裏付け。

## 実測で「問題なし」と確認したもの（誤検出の訂正を兼ねる）

- 設定>ネットワークの「先にアドレスを入力してください。」は、UIA矩形だけ見ると入力欄と重なるように見えたが、実画面では入力欄の下に正しく表示されていた（aislop_network.png）。重なりではない。
- かんたん表示のホームは大きな3ボタン（ファイルを送る/ファイルを受け取る/安全に保存する）で明快。この画面は「ポンだし感」が薄い。
- 設定>危険な操作の導入文（「ここにある操作はデータを削除し、元に戻せません。どの操作も、実行前に何が消えるかを示して確認を求めます。」）は明快で口調も統一されている。全体が均一に雑なのではなく、画面ごとに仕上げの度合いが違うこと自体が、生成＋部分手入れの痕跡に見える。
