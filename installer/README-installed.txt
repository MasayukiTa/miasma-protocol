Miasma Protocol (beta)
======================

Start Miasma from the Start menu ("Miasma"). On first run, click "Set Up Node".

Installed files (all in this folder):
  miasma-desktop.exe   the desktop app
  miasma.exe           command-line tool and background service; the desktop app
                       starts it for you and needs it next to miasma-desktop.exe
  miasma-bridge.exe    BitTorrent import helper

Your data is kept in your user profile (%LOCALAPPDATA%\miasma), not in this
folder. Uninstalling Miasma does not delete it.

This is a beta release and has not been independently audited. Do not use it
for highly sensitive data.

Help: https://github.com/MasayukiTa/miasma-protocol
