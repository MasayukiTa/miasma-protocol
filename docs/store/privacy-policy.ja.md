## 要点

- Miasma にはアカウントも広告も利用状況の分析もありません。提供者はファイルやメッセージや連絡先を預かるサーバーを運用していません。
- 鍵、連絡先、メッセージの履歴、保存したファイルはすべて自分の端末に残ります。
- ファイルやメッセージは選んだ相手に暗号化して送られます。二つのアプリをつなぐために第三者が運用する中継サーバーと探索サービスを使うことがあります。これらには接続の情報が見えますが、内容は見えません。
- Miasma はベータ版で、外部の監査を受けていません。漏れると重大な被害になる情報には使わないでください。

## 1. 端末の中に残るもの

| データ | 保存の場所と方法 |
|---|---|
| ノード鍵 (アプリを識別し、保存内容を暗号化する鍵) | 初回起動で作られます。Windows ではアプリのデータフォルダーに置かれます。Android ではアプリ専用の領域に置かれ、復旧用の控えは Android Keystore の鍵で包まれます。 |
| 連絡先 (付けた名前、連絡先コード、確認用コード) | デスクトップ版のみ。データフォルダーに保存されます。 |
| メッセージの履歴 | デスクトップ版のみ。初期設定では暗号化してディスクに保存します。設定でメモリ内だけにもできます。初期設定では、自分で消すまで残ります。 |
| 「安全に保存する」で保存したファイル | 端末の中に暗号化して保存されます。 |
| 受け取ったファイル | アプリから開ける受信フォルダーに書き込まれます。普通のファイルです。 |
| 転送の一覧、設定、共有の一覧 | データフォルダーに保存されます。 |
| ログファイル | 初期設定では作りません。診断ログは、オンにしない限りオフです。オンにすると、データフォルダーのログに、Miasma を使ったことと日時が残ります。 |

Windows に通常どおりインストールしたときのデータフォルダーは `%LOCALAPPDATA%\miasma\data` です。[所有者へ: Store 版の保存先を確認してください。MSIX のアプリではファイルの書き込みがパッケージ専用のフォルダーに振り替えられ、アンインストールで消えることがあります。この点は未検証です。]

アプリが自分から住所録、位置情報、写真を読むことはありません。読むのは自分で選んだファイルだけです。Android のカメラはスキャンのボタンを押したときに QR コードを読むためだけに使います。

## 2. 端末の外に出るもの

### 2.1 選んだ相手へ

ファイルやメッセージを送ると、内容は暗号化されて相手のアプリに届きます。提供者がそれを受け取ることはありません。接続があったことと端末のネットワークアドレスは、相手のアプリと、途中で接続を取り扱う側に見えます。

### 2.2 保存用の暗号化された断片

「安全に保存する」と Share ID での共有はファイルを暗号化した断片に分けます。アプリはその断片を保存先となる別の Miasma ノードに置くことがあります。保存先は内容を読めません。保管しているものの大きさと時刻、送ってきたアプリのネットワークアドレスは見えます。

自分の端末が、他の人の暗号化された断片を預かることもあります。デスクトップ版は初期設定でオンになっていて、上限は 1024 MiB です。設定は画面ではなく、ノードの設定ファイルで行います。上限を 0 にすると断片を一切受け付けません。[所有者へ: Store 版を最初からオフにするか決め、この段落を合わせてください。]

### 2.3 接続の準備: 中継サーバーと探索サービス

デスクトップ版は、可能なら二つのアプリを直接つなぎます。相手を探すときと直接つなげないときの中継には、iroh プロジェクト (運営は Number 0、n0.computer) の公開の中継サーバーと探索サービスを使います。これが初期の接続設定です。Miasma の起動中、これらのサービスには次の情報が伝わります。

- アプリのエンドポイント ID (公開鍵です。作った Share ID に含まれる発行者の鍵でもあります)
- 使っている中継サーバー
- 端末の IP アドレス

Share ID を持っている人は同じ方法でこのアプリを探せます。中継サーバーに見えるのは接続の情報と暗号化されたデータだけで、ファイルの内容は読めません。

コードが接続する先は `*.relay.n0.iroh.link` (中継サーバー `use1-1`、`usw1-1`、`euc1-1`、`aps1-1`) と `dns.iroh.link` です。これは Miasma が使う iroh ライブラリのバージョン 1.3.0 に由来し、ライブラリの更新で変わることがあります。

設定の「ネットワーク」の「接続方法」で変えられます。

- 公開の中継サーバー: 上で説明した初期設定です。
- 自分の中継サーバー: 登録した中継サーバーだけが通信を中継します。公開の探索サービスはノードの設定ファイルで `iroh_discovery` を false にしない限り使われます (設定画面にはありません)。
- 直接のみ: 中継の経路をオフにします。Share ID だけで受け取る方法は使えなくなります。

Android 版ではこの中継と探索のサービスはコードの中でオフです。Android 版は設定で入力した相手から接続を始めます。初期値の相手はありません。そのあとは、必要に応じて別の Miasma ノードに接続します。

### 2.4 同じネットワークの中

デスクトップ版は同じネットワーク内の探索が初期設定でオンです。同じネットワークにある二台が互いを見つけられるように、エンドポイント ID とローカルのアドレスを知らせます。同じネットワークにいる全員にこの知らせが見えます。設定の「ネットワーク」で「同じネットワーク内の探索」をオフにできます。

### 2.5 更新の確認 (デスクトップ版)

デスクトップ版は初期設定で、起動後に一度だけ新しいリリースがあるかを GitHub に問い合わせます (`api.github.com`、このプロジェクトのリリース)。同意すると更新ファイルをプロジェクトの GitHub のリリースからダウンロードします。GitHub には IP アドレスと問い合わせの時刻が伝わり、GitHub 自身のプライバシーポリシーが適用されます。設定の「更新」でオフ (GitHub に一切接続しない)、通知 (初期設定)、自動のどれかを選べます。

[所有者へ: Microsoft Store が更新を扱うため、Store 版を更新確認オフで出荷する場合は、この節を次の文に差し替えてください。「Microsoft Store 版は自分では更新を確認しません。更新は Microsoft Store から届きます。」この下書きの時点では、MSIX パッケージのときに更新確認を切るコードはソースにありません。]

### 2.6 Miasma が送らないもの

Miasma には広告や分析のコードがありません。クラッシュレポートや利用状況の統計や端末の識別子を、分析などの目的で提供者や第三者に送ることはありません。[所有者へ: この記述はプロジェクト自身のソースコードを検索した結果に基づきます。公開の前に依存関係の一覧全体と照らして確認してください。]

## 3. 第三者

| 相手 | 受け取るもの | 目的 |
|---|---|---|
| やり取りする相手の Miasma 利用者 | 送った内容、IP アドレス、エンドポイント ID | ファイルとメッセージを届けるため |
| 保存先のノード (他の Miasma ノード) | 暗号化された断片、IP アドレス | 保存や共有をしたファイルの断片を預かるため |
| Number 0 (iroh の中継サーバーと探索サービス) | エンドポイント ID、中継サーバー、IP アドレス。暗号化された通信は中継サーバーを通ります | 二つのアプリをつなぐため |
| GitHub | IP アドレス、更新確認の時刻 | 更新の確認とダウンロード |
| Microsoft、Google | ストアからインストールや更新をするときにストアが集める情報 | 配布。各社の方針に従います |

## 4. データの保持と削除

提供者はデータを持っていないので、消すものがありません。自分で消す方法は次のとおりです。

- ファイルの「完了分を消去」: 完了した転送を一覧から外します。受け取ったファイルや送ったファイルは消えません。
- チャット: 会話の履歴を端末から消します。
- 連絡先: 連絡先を削除します。
- 送ったファイル: 共有を取り消すと相手は受け取れなくなります。
- 設定の「緊急消去」(すべてのデータを消去): Miasma が端末に保存しているものを、それを開く鍵ごとすべて消します。元に戻せません。すでに相手に送ったコピーと、受信フォルダーなど別の場所に保存したファイルは消えません。
- アンインストール: デスクトップ版のインストーラーはアンインストールしてもデータフォルダーを残します。フォルダーを自分で消すか、先に「緊急消去」を使ってください。[所有者へ: Store 版の動作を確認してください。] Android ではアンインストールでアプリ専用の領域が消えます。アプリはシステムのバックアップも許可していません。

他の端末に置かれた暗号化された断片は、その持ち主が持っています。提供者を含め、誰もあなたの代わりに消すことはできません。鍵がなければ読めません。

## 5. セキュリティ

内容は端末を出る前に暗号化されます。Miasma はベータ版で外部の監査を受けていません。既知の限界は [SECURITY.md](../../SECURITY.md) にまとめてあります。連絡先は確認コードで必ず確かめてください。それが、意図した相手と話していることを確かめる手段です。

## 6. 子どもについて

Miasma は子どもを対象にしていません。[所有者へ: 適用する最低年齢 (たとえば 13 歳) を決め、各ストアのアンケートの回答と合わせてください。] 提供者は子どもを含め、誰の個人データも持っていません。

## 7. このポリシーの変更

アプリの動作が変わったときはこのポリシーを更新し、施行日を変えます。変更の履歴はプロジェクトのリポジトリで公開されています。
