# ストア申請の資料

日本語 | [English](README.md)

この資料は、Miasma を Microsoft Store (MSIX、個人開発者アカウント、登録は所有者があとで行う) と Google Play に申請する人のための準備です。所有者が確認するための下書きです。事実はすべて、このリポジトリのコードと文書から取っています。ビルドも実行も一切していません。書いたときに使った環境ではビルドが禁止されていたためです。

| 資料 | 内容 |
|---|---|
| [privacy-policy.ja.md](privacy-policy.ja.md) | プライバシーポリシー。所有者が埋める箇所は角かっこになっています |
| [microsoft-store.ja.md](microsoft-store.ja.md) | 掲載文、スクリーンショット、年齢区分、runFullTrust の説明、パッケージ ID、認定のチェックリスト、審査の懸念 |
| [google-play.ja.md](google-play.ja.md) | 掲載文、データセーフティ、権限、ターゲット API と 16 KiB、署名、コンテンツのレーティング、申請を止めているもの |

どの資料にも英語版があります。名前は、`.md` の前の `.ja` を除いたものです。

## 用語

資料はデスクトップアプリの Easy モードの言葉を使っています。ホーム、ファイルを送る、ファイルを受け取る、安全に保存する、連絡先、チャット、ファイル、設定、「招待コード」(Share ID を入れる欄)、「連絡先コード」、「確認コード」です。この資料を依頼されたときは三つ目の操作を「Keep safe」と呼んでいましたが、画面の表示は「安全に保存する」(英語では Save securely) なので、資料はそちらを使っています。

## 所有者への確認事項

1. Store 版の更新確認。デスクトップアプリは初期設定で起動時に GitHub へ更新を問い合わせ、インストールもできます。Store 版は更新オフで出し、設定欄を隠すべきでしょうか。コードの変更が要り、審査に落ちる原因として最も可能性が高い点です。プライバシーポリシーの角かっこは、この答えに左右されます。
2. 預かり保存。デスクトップのノードは初期設定で他の利用者の暗号化された断片を 1024 MiB まで預かります。設定画面にはその項目がありません。Store 版は最初からオフにしますか。
3. ポリシーとアンケートに入れる提供者名、施行日、最低年齢は何にしますか。
4. パッケージに簡体字中国語 (`zh-cn`) も宣言しますか。
5. インポートのタブ (BitTorrent に触れています) は、パッケージ版で表示されますか。表示されてよいですか。
6. Android について。アプリケーション ID は `dev.miasma` でよいですか。通知の権限を足しますか。Android の用語 (Content ID、チャレンジコード) をデスクトップの用語にそろえますか。
7. 「分析もクラッシュレポートもない」という記述はこのリポジトリのソースを検索した結果に基づきます。依存関係の一覧全体と照らして確認してください。
