# 画面の文言の書き方

Miasma デスクトップ版の画面に出す文言（日本語・英語・簡体字中国語）をそろえるための決まりです。文言は `crates/miasma-desktop/src/locale.rs` と `locale/` 配下、`network_strings.rs`、`hosting_strings.rs` にあります。3言語は同じキーと同じ `{穴}` を持たせます。

## 表記

| 項目 | 日本語の決まり |
|---|---|
| 読点 | 助詞のすぐ後ろには打たない（「連絡先と短いメッセージ」。「連絡先と、短い…」は不可）。条件や理由で文が切れるところ（「…すると、」「…ので、」）は打ってよい。 |
| ラベルの区切り | 全角コロン「：」を後ろに付け、空白は入れない（「状態：」「保存先：{path}」）。半角「:」は使わない。英語は半角「:」、中国語は全角「：」。 |
| 括弧 | 全角括弧で、前後に空白を入れない（「ビット（Mbps）」「（例：24h）」）。例外は設けない。URL やコードの中の半角記号はそのまま。 |
| 時間・件数 | 数字と単位を詰める（3秒前、1分前、2時間、5件、12文字、4人）。 |
| 容量 | 数字と単位の間に半角空白を入れる（1 GiB、256 MiB）。 |
| 半角カンマ | 使わない（列挙は「、」か「・」）。 |
| 末尾の「…」 | 完了条件が分からない「準備中…」で流さない。状態は1行に1つにし、「·」でつながない。 |

## 用語

1つの概念には1つの語を使います。

| 語 | 指すもの | 補足 |
|---|---|---|
| 招待 | 相手に送る、連絡先コードを含んだメッセージ全体 | 「招待メッセージ」「あなたの招待」 |
| 連絡先コード | 連絡先を追加するための長いコード（`miasma-contact:` で始まる） | 人に見せても構わない。パスワードではない |
| 確認用コード | 連絡先が本人かを、電話などで読み上げて見比べる短いコード | 「確認コード」とは書かない。グループのメンバーメニューも同じ語 |
| 受信コード | プライベート送信で、送り先を指定するコード（`msk:...@PeerId`） | 「ファイル受信コード」「送信先の連絡先コード」とは書かない |
| ワンタイムコード | プライベート送信で、受け手が読み上げ、送り手が入力する1回限りのコード | 旧「チャレンジ」「確認コード」 |
| 共有ID | ファイル転送で受け手に渡す ID（`miasma-share:` で始まる） | かんたん表示では「招待コード」と呼ぶ |
| コンテンツID | 保存した内容の ID（`miasma:` で始まる） | 「MID」とは書かない。英語の技術表示だけ「Content ID (MID)」 |
| 断片 | 暗号化して分けたデータの1つ | 「ピース」とは書かない |

### 共有IDとコンテンツIDの使い分け

- 保存・取得・復元の画面は「コンテンツID」。
- ファイル転送の受信欄は「共有ID（またはコンテンツID）」。どちらも貼れるため両方を書く。
- 受け手に渡すのは共有ID。コンテンツIDは内部用なので、受け取りには使えないと明記する。

## 言い回し

- 退出は「退出する」。「抜ける」は使わない。
- 再起動が必要な設定は、すべて「変更は Miasma の再起動後に反映されます。」と書く（英語は “Changes take effect after Miasma restarts.”）。
- 同じ画面では、相手の人は「相手」、登録済みの人は「連絡先」と書く。「ユーザー」は使わない。取り決めのない第三者は「他の人」とする。
- 「ワンクリックで」「正確に」「諦めずに」など、宣伝や口語の言い回しは使わない。
- 見出しをなぞるだけの説明文、選んだ値を言い直すだけの文、初期値の注釈は書かない。安全・プライバシー・元に戻せない操作・届かない理由は、短くても残す。
- 日本語は直訳にしない。「〜することができます」を避け、主語を短くする。
